<h1> 🎉 Birthday Card Webpage 🎂</h1> 

Welcome to the **Birthday Card Webpage** project! This webpage is designed to showcase a visually stunning and heartfelt birthday card with beautiful design elements and interactive features.

It includes an image-based birthday card with customizable text, vibrant colors, and an interactive "Read More" button. The webpage is built using HTML and CSS for a modern, responsive design.

---

## 🌟 Features

- **Interactive and Personalized Card**: Displays a beautiful birthday card image along with personalized messages.
- **Vibrant Design**: Bold color scheme with rounded corners, elegant typography, and fun styling elements.
- **Responsive Layout**: The design adapts seamlessly across different screen sizes for a great user experience.
- **Engaging Buttons**: A "Read More" button that allows users to interact and expand the birthday message.

---

## 🚀🛠️ Technologies Used
- HTML5: For structuring the webpage content.
- CSS3: For styling the webpage and creating a responsive design.
- Google Fonts: Custom fonts used for a more polished appearance (Lobster, Playwrite HR Lijeva, Yuji Mai).
